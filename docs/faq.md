# 进销存管理系统常见问题解答 (FAQ)

## 1. 系统访问与登录

### 1.1 如何访问系统？
- 打开浏览器，输入系统网址：http://localhost:3000（开发环境）或生产环境网址
- 进入登录页面后，输入用户名和密码登录

### 1.2 忘记密码怎么办？
1. 在登录页面点击"忘记密码"链接
2. 输入用户名和注册邮箱
3. 点击"发送验证码"按钮
4. 输入邮箱收到的验证码
5. 设置新密码
6. 点击"确认"按钮

### 1.3 账户被锁定了怎么办？
- 连续5次输入错误密码后，账户会被锁定30分钟
- 30分钟后自动解锁，或联系系统管理员手动解锁

### 1.4 如何更换浏览器？
- 系统支持主流浏览器，包括Chrome、Firefox、Safari、Edge
- 建议使用Chrome 90+或Edge 90+版本，以获得最佳体验

## 2. 系统配置与维护

### 2.1 如何修改系统配置？
- 系统管理员可以通过"系统管理" -> "系统配置"菜单修改系统参数
- 普通用户无权修改系统配置

### 2.2 如何备份系统数据？
1. 系统管理员登录系统
2. 进入"系统管理" -> "数据备份"菜单
3. 点击"备份数据"按钮
4. 系统会自动创建数据备份，并显示备份记录

### 2.3 如何恢复系统数据？
1. 系统管理员登录系统
2. 进入"系统管理" -> "数据备份"菜单
3. 在备份记录列表中选择要恢复的备份
4. 点击"恢复数据"按钮
5. 系统会提示确认，确认后开始恢复数据

### 2.4 系统定期维护时间是什么时候？
- 系统每周日凌晨2:00-4:00进行定期维护
- 维护期间系统可能暂时不可用，请提前做好安排

## 3. 采购管理

### 3.1 如何创建采购订单？
1. 进入"采购管理" -> "采购订单管理"页面
2. 点击"新增采购订单"按钮
3. 填写采购订单基本信息，包括供应商、采购日期、交货日期等
4. 添加采购商品明细，包括商品名称、规格、数量、单价等
5. 点击"保存"按钮

### 3.2 采购订单可以修改吗？
- 未审批的采购订单可以直接修改
- 已审批的采购订单需要先撤销审批，然后才能修改
- 已执行的采购订单不可修改，只能通过采购退货流程处理

### 3.3 如何查询采购历史记录？
1. 进入"采购管理" -> "采购报表" -> "采购历史查询"页面
2. 设置查询条件，包括时间范围、供应商、商品等
3. 点击"查询"按钮
4. 系统将显示符合条件的采购记录

## 4. 库存管理

### 4.1 如何进行库存调拨？
1. 进入"库存管理" -> "库存调拨"页面
2. 点击"新增调拨单"按钮
3. 选择调出仓库和调入仓库
4. 添加调拨商品明细，包括商品名称、数量等
5. 点击"保存"按钮
6. 调拨单审核通过后，系统自动更新库存

### 4.2 如何设置库存预警？
1. 进入"库存管理" -> "库存设置" -> "库存预警设置"页面
2. 选择商品，设置最低库存和最高库存
3. 点击"保存"按钮
4. 当库存低于最低库存或高于最高库存时，系统会自动发送预警通知

### 4.3 如何处理过期库存？
1. 进入"库存管理" -> "库存预警"页面
2. 查看过期库存列表
3. 点击"处理"按钮，选择处理方式（销毁、退货、降价处理等）
4. 填写处理结果，点击"保存"按钮

## 5. 销售管理

### 5.1 如何创建销售订单？
1. 进入"销售管理" -> "销售订单管理"页面
2. 点击"新增销售订单"按钮
3. 填写销售订单基本信息，包括客户、销售日期、交货日期等
4. 添加销售商品明细，包括商品名称、规格、数量、单价等
5. 点击"保存"按钮

### 5.2 如何处理销售退货？
1. 进入"销售管理" -> "销售退货管理"页面
2. 点击"新增销售退货"按钮
3. 选择对应的销售订单
4. 添加退货商品明细，包括商品名称、数量、退货原因等
5. 点击"保存"按钮
6. 退货单审核通过后，系统自动更新库存和财务数据

### 5.3 如何查看销售报表？
1. 进入"销售管理" -> "销售报表"页面
2. 选择报表类型（销售趋势分析、销售排名分析、销售毛利分析等）
3. 设置分析期间和分析维度
4. 点击"生成报表"按钮
5. 系统将生成对应的销售报表

## 6. 财务管理

### 6.1 如何录入发票？
1. 进入"财务管理" -> "发票管理"页面
2. 点击"新增发票"按钮
3. 选择发票类型（采购发票或销售发票）
4. 填写发票基本信息，包括发票号码、金额、税率等
5. 关联对应的订单
6. 点击"保存"按钮

### 6.2 如何进行付款登记？
1. 进入"财务管理" -> "付款管理"页面
2. 点击"新增付款"按钮
3. 选择付款对象（供应商）
4. 填写付款金额和付款方式
5. 关联对应的发票或采购订单
6. 点击"保存"按钮

### 6.3 如何生成财务报表？
1. 进入"财务管理" -> "财务报表"页面
2. 选择报表类型（资产负债表、利润表、现金流量表）
3. 选择报表期间
4. 点击"生成报表"按钮
5. 系统将生成并显示对应的财务报表

## 7. 系统性能与优化

### 7.1 系统运行缓慢怎么办？
- 检查网络连接是否正常
- 关闭浏览器中不必要的标签页和扩展程序
- 清除浏览器缓存和Cookie
- 升级浏览器到最新版本
- 如问题持续存在，请联系系统管理员

### 7.2 如何提高数据查询速度？
- 减少查询条件，缩小查询范围
- 优化查询条件，使用索引字段
- 避免在高峰期进行大规模数据查询
- 定期清理不必要的数据

## 9. 安全与权限

### 9.1 如何设置用户权限？
1. 系统管理员登录系统
2. 进入"系统管理" -> "角色管理"菜单
3. 创建或编辑角色，设置角色权限
4. 进入"系统管理" -> "用户管理"菜单
5. 为用户分配角色

### 9.2 如何查看操作日志？
1. 系统管理员登录系统
2. 进入"系统管理" -> "系统日志"菜单
3. 选择日志类型和时间范围
4. 点击"搜索"按钮
5. 系统将显示符合条件的操作日志

### 9.3 如何确保数据安全？
- 系统采用HTTPS加密传输
- 定期备份数据
- 严格的权限管理
- 操作日志审计
- 数据访问加密
