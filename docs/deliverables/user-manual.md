## 1. 系统概述

### 1.1 产品定位

进销存管理系统（Inventory Management System）是一套面向中小型及成长型企业的全链路业务管理平台，覆盖从采购入库、销售出库到财务结算的完整业务闭环。系统基于微服务架构设计，各模块可独立部署、灵活扩展，帮助企业实现：

- **采购端**：从供应商选择到采购入库的全流程管控
- **销售端**：从客户下单到销售出库的订单履约
- **库存端**：多仓库、多批次的精细化库存管理
- **财务端**：应收应付、成本核算与发票管理的业财一体化

### 1.2 核心价值

| 价值维度 | 说明 |
|---------|------|
| **全链路可视** | 采购→库存→销售→财务，数据一脉相承，告别信息孤岛 |
| **精细化管控** | 批次管理、库存预警、信用管控，风险提前预警 |
| **业财一体** | 业务单据自动生成财务凭证，减少手工对账 |
| **灵活扩展** | 微服务架构，按需启用模块，伴随企业成长 |
| **安全可靠** | 多因素认证、数据加密、操作审计，保障数据安全 |

### 1.3 技术特色

- **前端**：React 19 + Vite，响应式设计，支持PC与平板访问
- **网关安全**：API Key验证、IP白名单过滤、JWT鉴权、全链路审计日志
- **数据安全**：BCrypt 12轮加密存储、CSP/HSTS/XSS多层防护、CORS白名单策略
- **高可用架构**：Eureka服务注册与发现，支持服务横向扩展
- **数据库兼容**：同时支持 MySQL 与 PostgreSQL

### 1.4 系统架构概览

```
用户浏览器 → Spring Cloud Gateway（鉴权/限流/审计）
               ↓
         Eureka 服务注册中心
               ↓
   ┌───────────┼───────────┐
   ↓           ↓           ↓
采购服务    库存服务    销售服务  ……（共13个微服务）
   ↓           ↓           ↓
   └───────────┼───────────┘
               ↓
        MySQL / PostgreSQL
```

## 2. 快速入门

### 2.1 首次登录

#### 操作步骤

1. 打开浏览器，输入系统地址（如 `https://ims.yourcompany.com`）
2. 进入登录页面，输入管理员分配的**用户名**和**初始密码**
3. 若已启用MFA双因素认证，打开手机认证器App，输入6位动态验证码
4. 点击**【登录】**按钮进入系统

> ⚠️ **注意**：首次登录后，系统将强制要求修改初始密码。新密码需满足密码策略要求（见 3.12 认证授权章节）。

#### 登录失败常见原因

| 现象 | 可能原因 | 解决办法 |
|------|---------|---------|
| 提示"用户名或密码错误" | 输入有误或Caps Lock开启 | 检查大小写，重新输入 |
| 提示"账户已锁定" | 连续输错密码超过锁定次数 | 联系系统管理员解锁 |
| 提示"MFA验证码无效" | 验证码过期或设备时间不同步 | 刷新验证码，校准手机时间 |
| 页面无法打开 | 网络问题或IP未加白名单 | 检查网络，联系IT确认IP白名单 |

### 2.2 系统初始化

首次使用系统时，需完成以下初始化配置：

#### 步骤一：基础信息设置

1. 进入**【系统管理】→【系统配置】**
2. 填写企业基本信息：公司名称、统一社会信用代码、地址、联系方式
3. 设置默认币种、税率、结算方式
4. 点击**【保存】**

#### 步骤二：仓库初始化

1. 进入**【库存管理】→【仓库管理】**
2. 点击**【新增仓库】**，填写：
   - 仓库名称（如"华东总仓"）
   - 仓库编码（如"WH-HD-01"）
   - 仓库地址
   - 负责人
3. 依次创建所有仓库
4. 点击**【启用】**激活仓库

#### 步骤三：产品数据导入

1. 进入**【产品管理】→【产品列表】**
2. 点击**【导入】**按钮
3. 下载导入模板，按模板格式填写产品信息
4. 上传填写好的模板文件
5. 系统校验通过后，点击**【确认导入】**

> 💡 **提示**：产品数量较少时，也可通过**【新增产品】**逐条录入。

#### 步骤四：供应商与客户档案

1. 进入**【供应商管理】→【供应商列表】**，新增供应商信息
2. 进入**【客户管理】→【客户列表】**，新增客户信息
3. 为客户设置信用额度（见 3.6 客户管理章节）

#### 步骤五：用户与权限

1. 进入**【系统管理】→【用户管理】**，创建操作员账号
2. 进入**【系统管理】→【角色管理】**，定义角色并分配权限
3. 将用户分配到对应角色

### 2.3 基础配置向导

系统提供**配置向导**功能，帮助新用户快速完成初始化：

1. 首次登录后，系统自动弹出**配置向导**
2. 按向导指引依次完成：企业信息→仓库设置→产品导入→供应商/客户→用户权限
3. 每完成一步，向导显示进度并标记已完成项
4. 全部完成后，向导自动关闭

> 💡 **提示**：可随时通过右上角**【帮助】→【配置向导】**重新打开。

## 3. 功能模块操作指南

### 3.1 采购管理

#### 功能说明

采购管理模块覆盖采购业务全流程，包括采购订单创建、供应商管理、采购入库和采购退货。帮助采购团队规范采购流程、控制采购成本、追踪采购履约。

#### 3.1.1 采购订单创建

**操作步骤**：

1. 进入**【采购管理】→【采购订单】**
2. 点击**【新建订单】**
3. 填写订单基本信息：
   - **供应商**：从下拉列表选择（支持搜索）
   - **交货日期**：选择期望到货日期
   - **仓库**：选择入库目标仓库
   - **备注**：填写订单说明（选填）
4. 添加采购明细：
   - 点击**【添加产品】**，搜索并选择产品
   - 填写**采购数量**和**采购单价**
   - 可逐行添加多个产品
5. 系统自动计算订单总金额
6. 点击**【保存草稿】**或**【提交审批】**

> ⚠️ **注意**：提交审批后，订单状态变为"待审批"，不可修改。如需修改，请联系审批人驳回。

#### 3.1.2 采购入库（重点流程）

采购入库是采购业务的关键环节，确保实物与订单一致后完成入库。

**操作步骤**：

1. 供应商送货到达后，进入**【采购管理】→【采购入库】**
2. 点击**【新建入库单】**
3. **关联采购订单**：
   - 点击**【选择订单】**，系统弹出待入库的采购订单列表
   - 选择对应的采购订单，系统自动带入订单明细
4. **核对入库信息**：
   - 逐一核对实收数量，修改**实收数量**字段
   - 若有差异，在**差异说明**中注明原因
   - 系统自动计算**入库金额**（实收数量 × 采购单价）
5. **批次管理**（如启用）：
   - 为每个产品选择或创建批次号
   - 填写生产日期和有效期（如适用）
6. 点击**【确认入库】**
7. 系统自动完成以下操作：
   - 更新库存数量（目标仓库对应SKU库存增加）
   - 生成库存批次记录
   - 生成应付账款记录（财务模块）
   - 更新采购订单状态为"已入库"或"部分入库"

**注意事项**：

- 入库前务必**实物清点**，确保实收数量与填写一致
- 入库确认后不可撤销，如需调整请走**采购退货**流程
- 批次号一旦创建不可修改，请仔细核对
- 入库操作会同步影响财务应付账款，请确保金额正确

**常见问题**：

| 问题 | 解决办法 |
|------|---------|
| 找不到对应的采购订单 | 确认订单已审批通过，且状态为"待入库"或"部分入库" |
| 实收数量大于订单数量 | 系统默认不允许超收，如需超收请修改系统配置 |
| 入库后库存未增加 | 检查仓库是否已启用，联系管理员排查 |
| 忘记填写批次号 | 可在库存管理中补录批次信息 |

#### 3.1.3 采购退货

**操作步骤**：

1. 进入**【采购管理】→【采购退货】**
2. 点击**【新建退货单】**
3. 选择原采购入库单，系统带入入库明细
4. 填写退货产品、数量和退货原因
5. 点击**【提交】**
6. 系统自动扣减库存、生成红字应付记录

> ⚠️ **注意**：退货数量不能超过原入库数量。

### 3.2 销售管理

#### 功能说明

销售管理模块覆盖销售全流程，从客户下单到销售出库、销售退货，帮助销售团队高效管理订单、跟踪履约进度、控制客户信用风险。

#### 3.2.1 销售订单创建

**操作步骤**：

1. 进入**【销售管理】→【销售订单】**
2. 点击**【新建订单】**
3. 填写订单信息：
   - **客户**：从下拉列表选择
   - **交货日期**：选择承诺交货日期
   - **仓库**：选择出库仓库
   - **销售员**：自动填入当前用户，可修改
4. 添加销售明细：
   - 点击**【添加产品】**，搜索并选择产品
   - 填写**销售数量**和**销售单价**
   - 系统实时显示当前库存可用量
5. 系统自动检查客户信用额度：
   - 信用充足：正常提交
   - 信用不足：提示超额度警告，需审批
6. 点击**【保存草稿】**或**【提交】**

> ⚠️ **注意**：销售数量超过可用库存时，系统给出预警提示，但不会阻止提交（允许预销售模式）。

#### 3.2.2 销售出库（重点流程）

销售出库是订单履约的核心环节，确保正确的产品从正确的仓库发出。

**操作步骤**：

1. 进入**【销售管理】→【销售出库】**
2. 点击**【新建出库单】**
3. **关联销售订单**：
   - 点击**【选择订单】**，选择待出库的销售订单
   - 系统自动带入订单明细和指定仓库
4. **核对出库信息**：
   - 确认出库仓库（可修改，但需有足够库存）
   - 填写实际出库数量
   - 选择出库批次（先进先出原则，系统自动推荐最早批次）
5. **物流信息**（选填）：
   - 填写物流公司、运单号
   - 填写收货地址（默认取客户地址，可修改）
6. 点击**【确认出库】**
7. 系统自动完成以下操作：
   - 扣减库存数量（对应仓库SKU库存减少）
   - 扣减批次库存
   - 生成应收账款记录（财务模块）
   - 更新销售订单状态为"已出库"或"部分出库"
   - 触发库存预警检查

**注意事项**：

- 出库前务必**核对产品与数量**，确保实物与单据一致
- 系统默认推荐**先进先出**批次，建议优先采用，避免库存积压
- 出库确认后库存立即扣减，不可撤销
- 超额出库（超出订单数量）需审批

**常见问题**：

| 问题 | 解决办法 |
|------|---------|
| 出库时提示库存不足 | 检查库存可用量，考虑从其他仓库调拨或修改出库数量 |
| 批次选择不正确 | 可手动切换批次，但需注意有效期管理 |
| 出库后客户要求修改地址 | 出库前可修改；出库后需联系物流变更 |
| 出库单与订单数量不一致 | 支持分批出库，剩余数量可创建新出库单 |

#### 3.2.3 销售退货

**操作步骤**：

1. 进入**【销售管理】→【销售退货】**
2. 点击**【新建退货单】**
3. 选择原销售出库单
4. 填写退货产品、数量和退货原因
5. 选择退货入库仓库
6. 点击**【提交】**
7. 系统自动增加库存、生成红字应收记录

### 3.3 库存管理

#### 功能说明

库存管理模块是系统的核心枢纽，提供多仓库、多批次的精细化库存管理，包括库存查询、库存预警、库存调拨、批次管理和仓库管理。

#### 3.3.1 库存查询

**操作步骤**：

1. 进入**【库存管理】→【库存查询】**
2. 可通过以下条件筛选：
   - 仓库：选择特定仓库或"全部仓库"
   - 产品：按产品名称、编码或SKU搜索
   - 分类：按产品分类筛选
   - 库存状态：正常 / 预警 / 缺货
3. 查看库存明细：
   - **可用库存**：可用于销售的库存量
   - **在途库存**：已采购未到货的数量
   - **锁定库存**：已分配未出库的数量
   - **实际库存** = 可用库存 + 锁定库存
4. 支持导出为Excel

#### 3.3.2 库存预警

**操作步骤**：

1. 进入**【库存管理】→【库存预警】**
2. 设置预警规则：
   - 为每个产品设置**最低库存量**和**最高库存量**
   - 可按分类批量设置
3. 系统自动检测并展示预警列表：
   - 🔴 **缺货预警**：库存 ≤ 0
   - 🟡 **低库存预警**：库存 < 最低库存量
   - 🔵 **超储预警**：库存 > 最高库存量
4. 支持开启**自动通知**：预警触发时邮件/站内信通知相关负责人

> 💡 **提示**：建议每周查看预警列表，及时补货或处理滞销品。

#### 3.3.3 库存调拨

**操作步骤**：

1. 进入**【库存管理】→【库存调拨】**
2. 点击**【新建调拨单】**
3. 选择**调出仓库**和**调入仓库**
4. 添加调拨产品和数量
5. 填写调拨原因
6. 点击**【提交】**
7. 调拨单审批通过后，系统自动完成两个仓库的库存增减

#### 3.3.4 库存盘点（重点流程）

库存盘点是确保账实相符的重要操作，需定期执行。

**操作步骤**：

1. **创建盘点任务**：
   - 进入**【库存管理】→【库存盘点】**
   - 点击**【新建盘点】**
   - 选择盘点范围：全仓盘点 / 分类盘点 / 指定产品盘点
   - 选择盘点仓库
   - 点击**【创建】**，系统自动生成盘点单，带入账面库存数据

2. **执行实物盘点**：
   - 打印盘点单（点击**【打印】**），到仓库实地清点
   - 回到系统，逐一填写**实盘数量**
   - 系统自动计算**盘盈/盘亏数量**（实盘数量 − 账面数量）

3. **差异确认**：
   - 检查盘盈/盘亏数据，确认是否合理
   - 对差异较大的项目，可**重新盘点**（点击**【重盘】**）
   - 填写**差异原因**（必填）

4. **盘点审核**：
   - 点击**【提交审核】**
   - 主管审核盘点结果

5. **盘点过账**：
   - 审核通过后，点击**【过账】**
   - 系统自动调整库存数量，使其与实盘数量一致
   - 生成盘盈/盘亏的库存变动记录和财务凭证

**注意事项**：

- 盘点期间建议**暂停出入库操作**，避免数据不一致
- 盘点单创建后，该范围内的库存数据被**冻结**（锁定），不可进行出入库
- 盘点过账后不可撤销，请务必确认数据准确
- 建议每月至少进行一次盘点，高频出入库产品可增加盘点频次
- 大规模盘点建议选择非营业时间进行

**常见问题**：

| 问题 | 解决办法 |
|------|---------|
| 盘点时无法出库 | 盘点范围库存已冻结，需完成盘点或取消盘点任务 |
| 盘盈/盘亏数据异常 | 检查是否有未过账的出入库单据，确认后重新盘点 |
| 盘点单无法过账 | 确认所有明细已填写实盘数量和差异原因，且已审核通过 |
| 误创建盘点单 | 在未提交审核前可点击【删除】取消 |

#### 3.3.5 仓库管理

**操作步骤**：

1. 进入**【库存管理】→【仓库管理】**
2. 可执行以下操作：
   - **新增仓库**：填写名称、编码、地址、负责人
   - **编辑仓库**：修改仓库信息
   - **启用/停用**：停用前需确保仓库无在途库存和未完成单据
   - **查看库存**：快速查看该仓库下的所有库存

## 4. 常见问题与FAQ

### 登录与账户

**Q1：忘记密码怎么办？**

在登录页面点击**【忘记密码】**，输入注册邮箱，系统发送密码重置链接，点击链接设置新密码。如邮箱也无法访问，请联系系统管理员重置。

**Q2：账户被锁定了怎么办？**

账户锁定通常因连续输错密码导致。可等待锁定时间结束后自动解锁，或联系系统管理员在**【系统管理】→【用户管理】**中手动解锁。

**Q3：MFA验证码无法使用怎么办？**

- 确认手机时间是否准确（自动校时）
- 确认扫描的是当前账号的二维码
- 如手机丢失，使用MFA恢复码登录，重新绑定新设备
- 如无恢复码，联系管理员重置MFA

**Q4：登录后系统自动退出怎么办？**

JWT令牌有效期默认2小时，长时间不操作也会自动登出。如在有效期内反复退出，检查网络连接是否稳定，或更换浏览器尝试。

### 采购相关

**Q5：采购订单提交后如何修改？**

提交审批前的草稿状态可直接编辑。已提交审批的订单需联系审批人**驳回**后才能修改。已审批通过的订单不可修改，如需调整可创建补充订单。

**Q6：采购入库时实收数量与订单不一致怎么办？**

在入库单中将实收数量修改为实际到货数量，并在差异说明中注明原因（如物流损耗、供应商少发等）。系统会自动更新采购订单状态为"部分入库"或"已入库"。

**Q7：采购退货后款项如何处理？**

采购退货提交后，系统自动生成红字应付记录，冲减对应供应商的应付账款。如已付款，红字记录会形成预付款余额，可用于后续采购抵扣。

### 销售相关

**Q8：销售时提示客户信用额度不足怎么办？**

当订单金额超过客户可用信用额度时触发警告。处理方式：
1. 联系客户付款，降低应收款以释放额度
2. 申请临时调增信用额度（需审批）
3. 要求客户先付款后发货

**Q9：销售出库后客户要求退货怎么办？**

在**【销售管理】→【销售退货】**中创建退货单，选择原出库单，填写退货信息。退货入库后系统自动增加库存并冲减应收款。

**Q10：如何分批出库？**

一张销售订单可创建多张出库单。第一次出库时填写部分数量，订单状态变为"部分出库"。后续继续创建出库单，直至全部出库完成。

### 库存相关

**Q11：库存盘点期间能否进行出入库操作？**

盘点范围内的库存会被冻结，不可进行出入库。如需紧急出库，请先取消或完成盘点任务。

**Q12：库存预警如何设置？**

在**【库存管理】→【库存预警】**中，为每个产品设置最低和最高库存量。也可按分类批量设置。当库存触发阈值时，系统自动在预警列表中显示，并可选择邮件/站内信通知。

**Q13：库存调拨需要审批吗？**

默认情况下，库存调拨单创建后需审批通过才执行。系统管理员可在审批模板中配置是否需要审批及审批人。

### 财务相关

**Q14：收付款登记后能否撤销？**

收付款登记后如未审核，可点击**【撤销】**。已审核的需联系财务主管处理。

**Q15：成本核算的方法能否更改？**

成本核算方法（移动加权平均/先进先出）一旦选定并过账，当期不可更改。下一核算周期可切换方法，但建议全年保持一致。

**Q16：财务凭证可以手动创建吗？**

可以。进入**【财务管理】→【凭证管理】**，点击**【新增凭证】**手动创建。但建议优先通过业务单据自动生成，确保业财数据一致。

### 发票相关

**Q17：发票开具后信息有误怎么办？**

已开具的发票不支持直接修改。需开具对应金额的**红字发票**冲红原发票，然后重新开具正确的蓝字发票。

### 系统相关

**Q18：如何导出数据？**

各列表页面均提供**【导出】**按钮，支持导出为Excel或PDF格式。部分报表还支持定时自动导出并发送邮件。

## 6. 术语表

| 术语 | 英文 | 解释 |
|------|------|------|
| **进销存** | PSI (Purchase-Sales-Inventory) | 采购、销售、库存的统称，是企业物资流转的三大核心环节 |
| **SKU** | Stock Keeping Unit | 最小库存单位，是产品的最小可售/可管理单元，如"红色M码T恤" |
| **批次** | Batch/Lot | 同一批入库的产品标识，用于追溯和管理同批次产品的质量与有效期 |
| **采购订单** | Purchase Order (PO) | 向供应商发出的采购要约，载明产品、数量、价格和交货要求 |
| **销售订单** | Sales Order (SO) | 与客户达成的销售协议，载明产品、数量、价格和交货承诺 |
| **入库单** | Inbound Receipt | 记录实物入库的单据，关联采购订单，确认实际入库数量 |
| **出库单** | Outbound Delivery | 记录实物出库的单据，关联销售订单，确认实际出库数量 |
| **盘点** | Stocktaking / Inventory Count | 对实物库存进行清点，与账面数据核对，确保账实相符 |
| **盘盈** | Inventory Gain | 实物数量大于账面数量，即盘点多出的库存 |
| **盘亏** | Inventory Loss | 实物数量小于账面数量，即盘点缺少的库存 |
| **调拨** | Transfer | 在不同仓库之间移转库存 |
| **应收账款** | Accounts Receivable (AR) | 客户因购买商品或服务而尚未支付的款项 |
| **应付账款** | Accounts Payable (AP) | 企业因采购商品或服务而尚未支付给供应商的款项 |
| **信用额度** | Credit Limit | 客户可赊销的最大金额，超过此额度需特殊审批 |
| **账龄** | Aging | 应收/应付账款从发生日到当前的时间长度，用于评估回款风险 |
| **先进先出** | FIFO (First In First Out) | 出库时优先发出最早入库批次的管理方法 |
| **移动加权平均** | Moving Weighted Average | 每次入库后重新计算库存单价的方法：总金额 ÷ 总数量 |
| **成本核算** | Cost Accounting | 计算产品采购成本、出库成本和期末库存成本的过程 |
| **财务凭证** | Accounting Voucher | 记录经济业务的会计凭证，包含借贷科目和金额 |
| **红字发票** | Red Invoice / Credit Note | 用于冲红原发票的负数发票，表示退货、折让等减少金额的情况 |
| **蓝字发票** | Blue Invoice | 正常开具的正数发票，与红字发票对应 |
| **JWT** | JSON Web Token | 一种安全的令牌格式，用于用户身份认证，系统签发后存储在浏览器中 |
| **MFA** | Multi-Factor Authentication | 多因素认证，除密码外还需提供第二种验证（如手机验证码），增强安全性 |
| **BCrypt** | BCrypt | 一种安全的密码哈希算法，系统使用12轮加密保护用户密码 |
| **微服务** | Microservice | 一种软件架构风格，将系统拆分为多个独立部署的小型服务 |
| **审批流** | Approval Workflow | 单据提交后按预设规则逐级审批的业务流程 |
| **库存冻结** | Inventory Freeze | 盘点等操作期间锁定库存，禁止出入库操作 |
| **在途库存** | In-Transit Inventory | 已采购但尚未到达仓库的库存 |
| **锁定库存** | Reserved/Allocated Inventory | 已被销售订单分配但尚未出库的库存 |
| **可用库存** | Available Inventory | 可供销售的实际库存 = 实际库存 − 锁定库存 |
| **CSP** | Content Security Policy | 内容安全策略，浏览器安全机制，防止XSS等攻击 |
| **HSTS** | HTTP Strict Transport Security | 强制使用HTTPS连接的安全策略 |
| **CORS** | Cross-Origin Resource Sharing | 跨域资源共享，系统通过白名单控制允许的跨域请求 |
