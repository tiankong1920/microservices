# 进销存管理系统用户手册

## 1. 文档概述

### 1.1 文档目的
本文档旨在指导用户如何使用进销存管理系统，包括系统的基本操作、功能模块的使用方法等。

### 1.2 文档范围
本文档涵盖了进销存管理系统的所有功能模块，包括：
- 系统登录与退出
- 采购管理
- 生产管理
- 库存管理
- 销售管理
- 财务管理
- 报表管理

### 1.3 适用对象
- 系统管理员
- 采购人员
- 生产人员
- 仓库管理人员
- 销售人员
- 财务人员

## 2. 系统登录与退出

### 2.1 系统登录
1. 打开浏览器，输入系统网址
2. 进入登录页面，输入用户名和密码
3. 点击"登录"按钮
4. 成功登录后，进入系统首页

### 2.2 系统退出
1. 点击页面右上角的用户头像
2. 在下拉菜单中选择"退出登录"
3. 系统将退出当前登录状态，返回登录页面

## 3. 采购管理模块

### 3.1 供应商管理

#### 3.1.1 供应商信息维护
1. 进入"采购管理" -> "供应商管理"页面
2. 点击"新增供应商"按钮
3. 填写供应商基本信息，包括供应商名称、联系方式、信用等级等
4. 点击"保存"按钮

#### 3.1.2 供应商查询
1. 进入"采购管理" -> "供应商管理"页面
2. 在搜索框中输入供应商名称或代码
3. 点击"搜索"按钮
4. 系统将显示符合条件的供应商列表

### 3.2 采购订单管理

#### 3.2.1 创建采购订单
1. 进入"采购管理" -> "采购订单管理"页面
2. 点击"新增采购订单"按钮
3. 填写采购订单基本信息，包括供应商、采购日期、交货日期等
4. 添加采购商品明细，包括商品名称、规格、数量、单价等
5. 点击"保存"按钮

#### 3.2.2 采购订单审批
1. 进入"采购管理" -> "采购订单管理"页面
2. 找到需要审批的采购订单
3. 点击"审批"按钮
4. 填写审批意见
5. 点击"同意"或"拒绝"按钮

### 3.3 收货管理

#### 3.3.1 收货登记
1. 进入"采购管理" -> "收货管理"页面
2. 点击"新增收货单"按钮
3. 选择对应的采购订单
4. 填写实际收货数量和质量检验结果
5. 点击"保存"按钮

## 4. 生产管理模块

### 4.1 生产订单管理

#### 4.1.1 创建生产订单
1. 进入"生产管理" -> "生产订单管理"页面
2. 点击"新增生产订单"按钮
3. 填写生产订单基本信息，包括产品名称、生产数量、计划开始日期、计划结束日期等
4. 系统自动分解BOM，生成生产所需的原材料清单
5. 点击"保存"按钮

#### 4.1.2 生产进度跟踪
1. 进入"生产管理" -> "生产进度管理"页面
2. 选择需要跟踪的生产订单
3. 查看生产进度看板，了解各工序的完成情况
4. 点击"更新进度"按钮，更新生产进度

### 4.2 质量检验

#### 4.2.1 质量检验记录
1. 进入"生产管理" -> "质量检验"页面
2. 点击"新增检验记录"按钮
3. 选择对应的生产订单或产品批次
4. 填写检验项目和检验结果
5. 点击"保存"按钮

## 5. 库存管理模块

### 5.1 库存查询
1. 进入"库存管理" -> "库存查询"页面
2. 选择查询条件，包括产品名称、仓库、批次等
3. 点击"查询"按钮
4. 系统将显示符合条件的库存信息

### 5.2 库存调拨
1. 进入"库存管理" -> "库存调拨"页面
2. 点击"新增调拨单"按钮
3. 选择调出仓库和调入仓库
4. 添加调拨商品明细，包括商品名称、数量等
5. 点击"保存"按钮
6. 调拨单审核通过后，系统自动更新库存

### 5.3 库存预警
1. 进入"库存管理" -> "库存预警"页面
2. 系统将显示所有库存预警信息，包括低库存、过期库存、滞销库存等
3. 点击预警记录，可以查看详细信息
4. 根据预警信息，采取相应的处理措施

## 7. 财务管理模块

## 10. 常见问题与故障排除

### 10.1 登录问题

#### 10.1.1 忘记密码
1. 在登录页面点击"忘记密码"链接
2. 输入用户名和注册邮箱
3. 点击"发送验证码"按钮
4. 输入邮箱收到的验证码
5. 设置新密码
6. 点击"确认"按钮

#### 10.1.2 账户被锁定
- 连续5次输入错误密码后，账户会被锁定30分钟
- 30分钟后自动解锁，或联系系统管理员手动解锁

### 10.2 操作问题

#### 10.2.1 无法保存数据
- 检查填写的信息是否完整和正确
- 检查网络连接是否正常
- 联系系统管理员

#### 10.2.2 数据查询缓慢
- 减少查询条件，缩小查询范围
- 优化查询条件，使用索引字段
- 避免在高峰期进行大规模数据查询
- 联系系统管理员

### 10.3 系统问题

#### 10.3.1 系统崩溃
- 刷新页面，重新登录
- 清除浏览器缓存和Cookie
- 升级浏览器到最新版本
- 联系系统管理员

#### 10.3.2 功能无法使用
- 检查是否有对应的权限
- 检查网络连接是否正常
- 关闭浏览器中不必要的标签页和扩展程序
- 联系系统管理员

### 10.4 更多常见问题

请参考单独的[常见问题解答 (FAQ) 文档](./faq.md)，其中包含更详细的问题解答和操作指南。
