# Web界面使用指南

## 1. 启动应用

### 1.1 启动后端服务
```bash
cd backend
mvn spring-boot:run
```

### 1.2 启动前端应用
```bash
cd frontend
npm install
npm run dev
```

## 2. 访问应用

启动完成后，可以通过以下URL访问应用：
- 前端应用: http://localhost:3000
- API文档: http://localhost:8080/swagger-ui.html

## 3. 销售订单管理功能

### 3.1 访问销售订单管理页面
在浏览器中访问 http://localhost:3000/sales-orders 或 http://localhost:3000 即可进入销售订单管理页面。

### 3.2 功能说明

#### 3.2.1 查看销售订单列表
- 页面加载后会自动获取所有销售订单并显示在表格中
- 表格包含订单号、客户ID、订单日期、总金额、状态等信息
- 支持分页显示，默认每页显示10条记录

#### 3.2.2 创建销售订单
1. 点击页面右上角的"创建销售订单"按钮
2. 在弹出的表单中填写销售订单信息：
   - 客户ID（必填）
   - 订单号（必填）
   - 订单日期（必填）
   - 状态（必填）
   - 折扣金额（可选）
   - 收银员（可选）
   - 备注（可选）
3. 点击"确定"按钮保存销售订单

#### 3.2.3 编辑销售订单
1. 在销售订单列表中找到要编辑的记录
2. 点击该记录行的"编辑"链接
3. 在弹出的表单中修改销售订单信息
4. 点击"确定"按钮保存修改

#### 3.2.4 删除销售订单
1. 在销售订单列表中找到要删除的记录
2. 点击该记录行的"删除"链接
3. 在确认对话框中点击"确定"按钮完成删除

### 3.3 API接口对应关系

前端界面操作与后端API接口的对应关系如下：

| 前端操作 | HTTP方法 | API端点 | 功能说明 |
|---------|---------|---------|---------|
| 查看销售订单列表 | GET | /api/v1/sales-orders | 获取所有销售订单 |
| 创建销售订单 | POST | /api/v1/sales-orders | 创建新的销售订单 |
| 编辑销售订单 | PUT | /api/v1/sales-orders/{id} | 更新指定ID的销售订单 |
| 删除销售订单 | DELETE | /api/v1/sales-orders/{id} | 删除指定ID的销售订单 |
| 查看销售订单详情 | GET | /api/v1/sales-orders/{id} | 获取指定ID的销售订单 |
| 根据订单号查询 | GET | /api/v1/sales-orders/order-number/{orderNumber} | 根据订单号获取销售订单 |
| 根据客户ID查询 | GET | /api/v1/sales-orders/customer/{customerId} | 根据客户ID获取销售订单列表 |
| 根据状态查询 | GET | /api/v1/sales-orders/status/{status} | 根据状态获取销售订单列表 |

## 4. 错误处理

### 4.1 常见错误及解决方案

#### 4.1.1 网络连接错误
- **错误现象**: 无法获取数据或操作失败
- **可能原因**: 后端服务未启动或网络问题
- **解决方案**: 
  1. 确认后端服务已启动
  2. 检查网络连接
  3. 确认API端点配置正确

#### 4.1.2 数据验证错误
- **错误现象**: 创建或更新销售订单时提示参数验证失败
- **可能原因**: 输入的数据不符合验证规则
- **解决方案**: 
  1. 检查必填字段是否已填写
  2. 确认数据格式正确（如日期格式、数字格式等）
  3. 根据提示信息修正错误数据

#### 4.1.3 权限错误
- **错误现象**: 操作被拒绝或返回403状态码
- **可能原因**: 当前用户没有执行该操作的权限
- **解决方案**: 
  1. 确认已登录系统
  2. 联系管理员确认用户权限

## 5. 最佳实践

### 5.1 数据输入建议
- 订单号应保持唯一性
- 客户ID应使用系统中已存在的客户标识
- 日期应使用标准格式（YYYY-MM-DD HH:mm:ss）
- 金额字段应使用正确的数值格式

### 5.2 操作建议
- 定期查看销售订单列表，及时处理待处理订单
- 删除订单前请确认是否真的需要删除
- 更新订单时注意版本冲突问题

通过以上指南，您可以顺利使用Web界面管理销售订单。如有其他问题，请参考API文档或联系技术支持。
