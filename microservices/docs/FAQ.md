## 2. 安装部署类问题

### 2.1 系统无法启动

**问题**：系统无法启动

**可能原因**：
1. Java未安装或版本过低
2. 数据库未启动
3. Redis未启动
4. Nacos未启动
5. 端口被占用
6. 配置文件错误

**解决方案**：
1. 检查Java是否安装：`java -version`
2. 检查Java版本是否满足要求（最低Java 21）
3. 检查数据库是否启动：`docker ps | Select-String "postgres"`
4. 检查Redis是否启动：`docker ps | Select-String "redis"`
5. 检查Nacos是否启动：`docker ps | Select-String "nacos"`
6. 检查端口是否被占用：`netstat -ano | Select-String "9090"`
7. 检查配置文件格式：验证YAML格式是否正确
8. 查看启动日志：`docker logs <service-name>`

### 2.2 端口被占用

**问题**：启动时提示端口被占用

**可能原因**：
1. 其他程序占用了相同端口
2. 之前的进程未正常退出
3. 配置文件中端口配置错误

**解决方案**：
1. 查找占用端口的进程：`netstat -ano | Select-String "9090"`
2. 终止占用进程：`Stop-Process -Id <pid> -Force`
3. 或修改服务端口：编辑配置文件，修改端口号
4. 重启服务

### 2.3 数据库连接失败

**问题**：系统无法连接到数据库

**可能原因**：
1. 数据库未启动
2. 数据库地址配置错误
3. 数据库端口配置错误
4. 数据库用户名或密码错误
5. 数据库防火墙阻止连接
6. 数据库连接池耗尽

**解决方案**：
1. 检查数据库是否启动：`docker ps | Select-String "postgres"`
2. 检查数据库连接配置：查看配置文件中的数据库地址和端口
3. 检查数据库用户名和密码：确认配置是否正确
4. 测试数据库连接：`docker exec postgres-1 pg_isready -U postgres`
5. 检查数据库防火墙：确保允许来自应用服务器的连接
6. 增加数据库连接池大小：修改配置文件中的连接池大小

### 2.4 Nacos连接失败

**问题**：系统无法连接到Nacos

**可能原因**：
1. Nacos未启动
2. Nacos地址配置错误
3. Nacos端口配置错误
4. 网络不通
5. Nacos命名空间配置错误

**解决方案**：
1. 检查Nacos是否启动：`docker ps | Select-String "nacos"`
2. 检查Nacos连接配置：查看配置文件中的Nacos地址和端口
3. 测试Nacos连接：`curl http://localhost:8848/nacos/v1/console/health/readiness`
4. 检查网络连接：`Test-NetConnection -ComputerName localhost -Port 8848`
5. 检查Nacos命名空间：确认配置文件中的命名空间是否正确

**问题**：设置环境变量后不生效

3. 重启服务：`docker restart <service-name>`
4. 检查环境变量名称：确认环境变量名称拼写正确
