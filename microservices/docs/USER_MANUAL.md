## 1. 文档概述

### 1.1 目的

本手册提供了库存管理系统的详细使用指南，包括系统概述、快速开始、功能介绍、用户界面说明、常用操作指南、权限管理和常见问题解答，旨在帮助用户快速上手和高效使用系统。

### 1.2 适用范围

- 系统安装和配置
- 功能使用和操作
- 用户界面导航
- 权限和角色管理
- 常见问题解答

### 1.3 目标读者

- 系统管理员
- 业务操作人员
- 库存管理人员
- 采购人员
- 销售人员
- 客户服务人员

### 1.4 术语定义

| 术语 | 定义 |
|------|------|
| **SKU（Stock Keeping Unit）**：库存单位，用于唯一标识产品 |
| **PO（Purchase Order）**：采购订单，用于记录采购交易 |
| **SO（Sales Order）**：销售订单，用于记录销售交易 |
| **ERP（Enterprise Resource Planning）**：企业资源计划系统 |
| **API（Application Programming Interface）**：应用程序编程接口 |
| **Dashboard**：仪表板，用于显示关键指标和图表 |
| **Workflow**：工作流，用于定义业务流程 |

## 2. 系统概述

### 2.1 系统功能

库存管理系统提供以下核心功能：

| 功能模块 | 功能描述 |
|---------|---------|
| **订单管理**：创建、查询、更新、取消订单 |
| **库存管理**：库存查询、库存调整、库存预警、库存盘点 |
| **产品管理**：产品列表、产品详情、产品创建、产品更新、产品删除 |
| **客户管理**：客户信息、客户查询、客户创建、客户更新、客户删除 |
| **供应商管理**：供应商信息、供应商查询、供应商创建、供应商更新、供应商删除 |
| **采购管理**：采购订单、采购入库、采购退货、采购审批 |
| **销售管理**：销售订单、销售出库、销售退货、销售审批 |

## 3. 快速开始

### 3.1 系统安装

#### 3.1.1 环境要求

| 要求 | 最低配置 | 推荐配置 |
|------|---------|---------|
| 操作系统 | Windows 10+ / Linux 4.x+ | Windows 11 / Linux 5.x+ |
| CPU | 2核 | 4核或以上 |
| 内存 | 4GB | 8GB或以上 |
| 磁盘 | 20GB | 50GB或以上 |
| 网络 | 100Mbps | 1Gbps |

#### 3.1.2 安装步骤

```powershell
# 步骤1：下载安装包
# 从官网下载最新版本的安装包

# 步骤2：解压安装包
# 解压到指定目录，如：E:\inventory-system

# 步骤3：配置环境变量
# 设置JAVA_HOME、POSTGRES_HOST、REDIS_HOST等环境变量

# 步骤4：启动依赖服务
cd nacos-cluster
docker-compose up -d

# 步骤5：启动应用服务
cd core-services
docker-compose up -d

# 步骤6：访问系统
# 打开浏览器访问：http://localhost:9090
```

### 3.2 系统配置

#### 3.2.1 数据库配置

```yaml
# 编辑 config/application.yml
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/inventory
    username: postgres
    password: postgres
    driver-class-name: org.postgresql.Driver
    hikari:
      maximum-pool-size: 20
      minimum-idle: 5
```

#### 3.2.2 Redis配置

```yaml
# 编辑 config/application.yml
spring:
  data:
    redis:
      host: localhost
      port: 6379
      password: ""
      database: 0
      timeout: 3000
```

#### 3.2.3 Nacos配置

```yaml
# 编辑 config/application.yml
spring:
  cloud:
    nacos:
      discovery:
        server-addr: localhost:8848
        namespace: public
      config:
        server-addr: localhost:8848
        namespace: public
        file-extension: yml
```

### 3.3 系统启动

#### 3.3.1 启动所有服务

```powershell
# 启动Nacos集群
cd nacos-cluster
docker-compose up -d

# 启动监控服务
cd ../monitoring
docker-compose up -d

# 启动支持服务
cd ../support-services
docker-compose up -d

# 启动核心服务
cd ../core-services
docker-compose up -d
```

#### 3.3.2 验证系统启动

```powershell
# 检查服务健康状态
curl http://localhost:9090/actuator/health
curl http://localhost:8080/actuator/health
curl http://localhost:8081/actuator/health

# 访问系统
# 打开浏览器访问：http://localhost:9090
```

## 4. 功能介绍

### 4.1 订单管理

#### 4.1.1 创建订单

1. **登录系统**：使用用户名和密码登录系统
2. **导航到订单管理**：点击"订单管理"菜单
3. **点击"创建订单"**：点击"创建订单"按钮
4. **填写订单信息**：
   - 客户信息
   - 产品信息
   - 数量
   - 单价
   - 交货日期
5. **提交订单**：点击"提交"按钮

#### 4.1.2 查询订单

1. **导航到订单管理**：点击"订单管理"菜单
2. **输入查询条件**：
   - 订单编号
   - 客户名称
   - 订单状态
   - 日期范围
3. **点击"查询"**：点击"查询"按钮
4. **查看订单列表**：系统显示符合条件的订单列表
5. **查看订单详情**：点击订单编号查看详细信息

#### 4.1.3 更新订单

1. **导航到订单管理**：点击"订单管理"菜单
2. **选择订单**：在订单列表中选择要更新的订单
3. **点击"编辑"**：点击"编辑"按钮
4. **修改订单信息**：修改需要更新的信息
5. **保存修改**：点击"保存"按钮

#### 4.1.4 取消订单

1. **导航到订单管理**：点击"订单管理"菜单

## 8. 常见问题解答

### 8.1 安装部署类问题

#### 8.1.1 系统无法启动

**问题**：系统无法启动

**解决方案**：
1. 检查Java是否安装：`java -version`
2. 检查数据库是否启动：`docker ps | Select-String "postgres"`
3. 检查Redis是否启动：`docker ps | Select-String "redis"`
4. 检查Nacos是否启动：`docker ps | Select-String "nacos"`
5. 查看启动日志：`docker logs <service-name>`

#### 8.1.2 端口被占用

**问题**：启动时提示端口被占用

**解决方案**：
1. 查找占用端口的进程：`netstat -ano | Select-String "9090"`
2. 终止占用进程：`Stop-Process -Id <pid> -Force`
3. 或修改服务端口：编辑配置文件，修改端口号

### 8.2 功能使用类问题

#### 8.2.1 无法创建订单

**问题**：无法创建订单

**解决方案**：
1. 检查库存是否充足
2. 检查客户信息是否完整
3. 检查产品信息是否完整
4. 检查是否有创建订单权限
5. 查看系统日志：`docker logs order-service`

#### 8.2.2 库存数据不准确

**问题**：库存数据不准确

**解决方案**：
1. 执行库存盘点
2. 检查入库记录
3. 检查出库记录
4. 检查库存调整记录
5. 联系技术支持

### 8.3 性能优化类问题

#### 8.3.1 系统响应慢

**问题**：系统响应速度慢

**解决方案**：
1. 检查网络连接
2. 检查数据库性能
3. 检查Redis缓存
4. 清理浏览器缓存
5. 联系技术支持

#### 8.3.2 页面加载慢

**问题**：页面加载速度慢

**解决方案**：
1. 检查网络连接
2. 清理浏览器缓存
3. 使用推荐浏览器（Chrome、Firefox、Edge）
4. 关闭不必要的浏览器插件
5. 联系技术支持
